# Islamic Tools

Free Islamic tools for Muslims in the UAE and worldwide, no sign-up needed. Visit the website: [oks.digital](https://oks.digital)

## What you can find

Prayer times for UAE and Pakistan cities: [Prayer Times](https://oks.digital/prayer-times/)

Qibla direction from anywhere in the world: [Qibla Finder](https://oks.digital/qibla-direction/)

Hijri and Gregorian date converter: [Hijri Date Converter](https://oks.digital/hijri-date-converter/)

Zakat calculator: [Zakat Calculator](https://oks.digital/zakat-calculator/)

Tasbeeh counter: [Tasbeeh Counter](https://oks.digital/tasbeeh-counter/)

Daily duas: [Daily Duas](https://oks.digital/daily-duas/)

Ramadan 2027 calendar for the UAE: [Ramadan Calendar 2027](https://oks.digital/ramadan-calendar-2027-uae/)

Islamic names for boys and girls: [Islamic Names for Boys](https://oks.digital/islamic-names-for-boys/) and [Islamic Names for Girls](https://oks.digital/islamic-names-for-girls/)
